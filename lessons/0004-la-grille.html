La grille

Un masque qui contient plusieurs lignes — et comment les parcourir.

L'en-tête [M:YNV0] tient une valeur par champ. La grille [M:YNV1] en tient plusieurs : chaque colonne est un tableau, indexé par ligne. On y accède avec un indice entre parenthèses.

[M:YNV1]PALNUM(0)   # palette de la 1re ligne
[M:YNV1]PALNUM(1)   # palette de la 2e ligne
[M:YNV1]QTY(I)      # quantité de la ligne I
La grille YNAVETTE = la liste des palettes de la navette à l'écran. Chaque ligne = une palette pickée : son n°, son article, sa quantité, sa commande. C'est ce que l'utilisateur construit en cliquant.

Le compteur : NBYNV

Combien de lignes sont réellement remplies ? Un champ compteur le dit — ici [M:YNV1]NBYNV. Les lignes valides vont de l'indice 0 à NBYNV-1. C'est la borne de toute boucle sur la grille :

For I = 0 To [M:YNV1]NBYNV-1
    Read [F:YSOH2]SOH0 = [M:YNV1]SOHNUM(I)   # lire la commande de la ligne I
    If [S]fstat = 0                          # (leçon 3 : on teste !)
        [M:YNV1]BPCORD(I) = [F:YSOH2]BPCORD  # base -> grille (leçon 2 : le sens)
    Endif
Next
Affzo [M:YNV1]                               # rafraîchir l'affichage

Trois acquis se combinent ici : la boucle (neuf), le test fstat (leçon 3), le transfert base→écran (leçon 2). C'est tout $LIENS2 : remplir le client de chaque ligne.

Ajouter une ligne : écrire à l'indice NBYNV

La première case libre est exactement à l'indice NBYNV (puisque les remplies vont jusqu'à NBYNV-1). Pour ajouter, on écrit là, puis on incrémente. C'est le geste de $PICKE :

[M:YNV1]PALNUM([M:YNV1]NBYNV) = [F:STJ]PALNUM   # nouvelle ligne = palette cliquée
[M:YNV1]SOHNUM([M:YNV1]NBYNV) = [F:SOH]SOHNUM
[M:YNV1]QTY([M:YNV1]NBYNV)    = [F:STJ]QTYSTU
[M:YNV1]NBYNV += 1                              # une ligne de plus

Garde-fou métier : l'anti-doublon

Avant d'ajouter, $PICKE vérifie que la palette n'est pas déjà dans la grille. Si oui → message + OK = 0 (souviens-toi : ça bloque l'action) + sortie :

For I = 0 To [M:YNV1]NBYNV-1
    If [M:YNV1]PALNUM(I) = [F:STJ]PALNUM
        Call ECR_TRACE("palette déjà sélectionnée",0) From GESECRAN
        OK = 0
        Return
    Endif
Next
Quand tu supprimes une ligne au milieu ($DEPICK avec Dela), les suivantes glissent d'un cran. Si tu ne recules pas l'indice (I-=1), tu sautes la ligne qui a pris la place. Boucle + suppression = toujours ce piège.

Leçon 6 · Fichiers · ~8 min

Écrire un fichier

Openo / Wrseq / Iomode — fabriquer le fichier d'import du BL.

Trois instructions, et deux pièges de syntaxe qui font perdre des heures (vécu). On les voit d'abord, puis le vrai GENERE_BL de YNAVETTE.

Le canal : un nom entre crochets, jamais un numéro

Openo "chemin/fichier.dat" Using [YIMP]   # ouvre en écriture, canal [YIMP]
Wrseq "ligne" Using [YIMP]                # écrit
Openo Using [YIMP]                        # FERME (Openo sans chemin = close)
Using attend une abréviation entre crochets ([YIMP]), librement choisie — pas un numéro de canal. Using 7 → « caractère illégal ». Et le verbe d'écriture est Wrseq, pas Writeseq. La fermeture est un Openo sans chemin.

Le séparateur : ;, posé une fois par Iomode

Pour un fichier d'import à champs séparés, on ne colle pas les valeurs à la main : on déclare le séparateur, puis on liste les champs séparés par ; dans Wrseq.

Iomode adxirs chr$(13)+chr$(10) Using [YIMP]   # séparateur de LIGNES = CR+LF
Iomode adxifs ";" Using [YIMP]                 # séparateur de CHAMPS = ;
Wrseq "H";[F:YSOH]SALFCY;[F:YSOH]BPCORD Using [YIMP]   # 3 champs, séparés par ;
  • adxifs = field separator (entre colonnes).
  • adxirs = record separator (entre lignes) = CR+LF via chr$().
  • Dans Wrseq, le ; sépare les champs — le moteur insère le adxifs à la place.
Ce fichier .dat n'est pas le BL « papier » : c'est un fichier d'import Sage. YNAVETTE l'écrit puis le réinjecte (IMPORTSIL) pour créer une livraison (SDELIVERY) dans l'ERP. Format classique : lignes préfixées H (en-tête), L (ligne), S (stock).

Le vrai GENERE_BL, décodé

If [L]YFICHIER_IMPORT=""
  [L]YFICHIER_IMPORT="YSDHFL_"+format$("D:YYYYMMDD[_]hhmmss",date$)
  Openo filpath("Import/DEF",[L]YFICHIER_IMPORT,"dat",""),0 Using [YIMP]
  Iomode adxirs chr$(13)+chr$(10) Using [YIMP]
  Iomode adxifs ";" Using [YIMP]
  Wrseq "H";[F:YSOH]SALFCY;[F:YSOH]STOFCY;"";[F:YSOH]BPCORD; ... Using [YIMP]
Endif
Read [F:YSOP]SOP0=[F:YSTA]VCRNUM;[F:YSTA]VCRLIN;[F:YSTA]VCRLIN
Wrseq "L";[F:YSTA]VCRNUM;[F:YSTA]ITMREF;[F:YSOP]ITMDES; ... Using [YIMP]
Wrseq "S";[F:YSTO]STA;[F:YSTO]PCU;[F:YSTO]PALNUM; ... Using [YIMP]

Lecture :

  • filpath("Import/DEF", nom, "dat", "") = construit un chemin folder-aware (portable, géré par X3). Toujours préférer à un chemin en dur.
  • format$("D:YYYYMMDD[_]hhmmss",date$) = horodatage dans le nom (les [ ] = littéral). Rappel : format date = format$, pas num$(date,fmt).
  • L'en-tête H n'est écrite qu'une fois (garde If YFICHIER_IMPORT="") ; les L/S à chaque tour.

Toujours fermer — et au bon moment

If [L]YFICHIER_IMPORT<>""
  Openo Using [YIMP]                                  # ferme
  Call IMPORTSIL("YSDH",filpath(...)) From GIMPOBJ    # puis on importe
Endif

On ferme avant d'importer : un fichier encore ouvert n'est pas entièrement écrit sur disque. Op d'écriture → close → consommation.
